# 🎨 Background Color Changer App (React Native)

This is a **React Native Background Color Changer App** that changes the background and status bar color to a random HEX color every time the button is pressed.  
It's a great beginner-friendly project to understand **React Native basics**, **state management**, and **random color generation**.

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd Background-Color-Changer
   ```

2. **Install the dependencies:**
   ```bash
   npm install
   ```

3. **Run the app on Android:**
   ```bash
   npx react-native run-android
   ```

4. **Or on iOS (Mac required):**
   ```bash
   npx react-native run-ios
   ```

## 🚀 How It Works

The app picks a random HEX value (like `#A1B2C3`) by combining 6 randomly selected characters from a HEX string.  
The selected color is then applied to:
- The entire app background (`View`)
- The device's status bar (`StatusBar`)
